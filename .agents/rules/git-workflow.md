# Git & Branching Workflow Rules

- **No Direct Push to Master**: Never push commits directly to the `master` branch. The master branch is protected.
- **Use Feature or Bugfix Branches**: Always create a dedicated branch (e.g. `feature/...`, `fix/...`, `chore/...`, `docs/...`) for any code or documentation changes.
- **Merge via Pull Request**: All changes must be reviewed and merged into `master` via a Pull Request (PR).
