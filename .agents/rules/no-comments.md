# No Comments Rule

- **Do NOT add code comments**: Never add comments (`// ...`, `/* ... */`, `<!-- ... -->`, `{/* ... */}`, `# ...`) when writing new code or modifying existing code.
- **Self-documenting code**: Code should be readable and clean through proper naming of variables, functions, and components rather than inline explanations.
- **No commented-out code**: Never leave dead or commented-out code.
- **No TODO / FIXME comments**: Do not add TODO or FIXME comments unless explicitly requested.
