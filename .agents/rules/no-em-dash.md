# No Em Dash Rule

- **Do NOT use the Em Dash**: Never use the em dash character (`—`, U+2014, or `--` as an em dash) in text.
- **Scope**: Applies to all contexts including UI copy, Hebrew text, English text, translations, code strings, markdown files, documentation, commit messages, and agent responses.
- **RTL & Hebrew Consideration**: Em dashes in Hebrew and RTL layouts can cause text flipping, alignment anomalies, or awkward spacing.
- **Alternative Punctuation**: Use standard punctuation instead, such as a regular hyphen (`-`), comma (`,`), colon (`:`), parentheses (`()`), or period (`.`), or rephrase the text.
